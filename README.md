# 啪嗒挑战

一个移动目标手速挑战小游戏。玩家需要追着画面里的目标点击，命中会推进当前图片进度，打空会倒扣；停手后进度会自动下跌，越接近满格下跌越快，进度满后按数字顺序解锁下一张图片。

## 试玩

在线试玩：https://rtuvd0335-ops.github.io/pata-tap-game/

本地试玩：直接打开 `index.html` 即可运行，不需要安装依赖。

## 内容

- 按数字文件名顺序展示图片
- 移动目标命中判定，打中涨进度，打空扣进度
- 每张图片独立进度条，停手会自动下跌
- 进度越高下跌越快，后面的图片目标更小更快
- 连击和精准命中会获得更高推进
- 点击反馈、音效和原创合成背景音乐
- 适配桌面和手机浏览器
